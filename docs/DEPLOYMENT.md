# Deployment Notes

## Render Setup

The app is configured for one-click deployment on Render via `render.yaml`.

### Required Environment Variables
- `DEBUG=false` (set automatically)
- `SECRET_KEY` (auto-generated by Render)

### Deploy Steps
1. Push to GitHub
2. Create new Web Service on Render
3. Connect repository
4. Deploy

## Local Development

### Backend
```bash
cd backend
python -m venv venv
./venv/bin/pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```

## Production Notes

- Database: SQLite for prototype, PostgreSQL recommended for production
- Static files: Served via Whitenoise
- File uploads: Stored in `uploads/` directory
- No authentication: Intentionally omitted for MVP (see TRADEOFFS.md)
